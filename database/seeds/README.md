# Seeds

This folder is intentionally empty. The synthetic dataset is generated by
[`scripts/generate_synthetic_data.py`](../../scripts/generate_synthetic_data.py)
into `data/synthetic/*.csv` and loaded into Supabase by
[`scripts/load_synthetic_data.py`](../../scripts/load_synthetic_data.py),
which calls `ingest_bank_transaction_atomic` and the other RPCs directly —
there is no static `.sql` seed file to keep in sync with the generator.
